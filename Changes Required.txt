In customer app they should be able to see the live movement of the driver moving towards their location in the maps, similar to Uber app.
In driver app the following logic should be implemented for pickup tasks. All drivers would divided into several groups catering to a particular location range each day. The group which is nearest to the customer would receive a popup which would mention the pickup  and drop location, the charge for that pickup task. Once a driver accepts a task then details about the driver name and contact number would be available for the customer. If no one in a particular group picks up that task , then it would show up in the next group who are in the adjacent location, when compared to the previous group. The task will keep showing up till it is accepted in each group one after the other. All such unaccepted tasks will show up as available orders for one group at one point in time, till it moves to another group.
