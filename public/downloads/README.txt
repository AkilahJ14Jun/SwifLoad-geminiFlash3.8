SwifLoad Mobile App Packages
------------------------------
This directory contains direct downloadable Android APKs and installer packages:
1. SwifLoad-Customer.apk - Customer Booking Mobile Application
2. SwifLoad-Driver.apk - Driver-Partner Delivery & Earnings Application

Progressive Web App (PWA):
Users can also open https://<your-azure-app-name>.azurewebsites.net/customer or /driver on any mobile phone browser and tap "Add to Home Screen" to install instantly without downloading .apk files.
