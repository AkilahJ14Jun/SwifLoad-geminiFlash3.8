  🚀 SwifLoad Live Cloud Deployment & Mobile App Release

  The SwifLoad logistics platform has been deployed to Microsoft Azure under akilahj@adwayit.com. The Admin Portal,
  Customer Web/App, and Driver-Partner Web/App are all bound to the centralized cloud database with real-time
  bidirectional Server-Sent Events (SSE) synchronization.

  ### 📱 Mobile Download & Installation Options

  Users can install SwifLoad onto Android and iOS devices in two ways:

  #### Option 1: Native Android APK Downloads

  • Customer App APK: https://swifload-cbe.azurewebsites.net/downloads/SwifLoad-Customer.apk https://swifload-cbe.
  azurewebsites.net/downloads/SwifLoad-Customer.apk (3.75 MB)
  • Driver App APK: https://swifload-cbe.azurewebsites.net/downloads/SwifLoad-Driver.apk https://swifload-cbe.
  azurewebsites.net/downloads/SwifLoad-Driver.apk (3.75 MB)
  • Both packages are pre-configured to connect to the cloud endpoint with native splash screen and GPS telematics.

  #### Option 2: 1-Tap Progressive Web App (PWA)

  • Open https://swifload-cbe.azurewebsites.net/downloads or either /customer or /driver on Chrome (Android) or Safari
  (iOS).
  • Tap "Install Customer App" or "Install Driver App" to add full-screen, standalone icons to the home screen.

  ### 🔄 Centralized Real-Time Sync Verification

  • Central Cloud State: /api/state https://swifload-cbe.azurewebsites.net/api/state maintains the canonical database
  of active drivers, trips, driver groups, and wallet balances.
  • Instant Broadcast: /api/events https://swifload-cbe.azurewebsites.net/api/events broadcasts updates (trip creation,
  driver acceptance, transit milestones, wallet credits) via SSE with 20s keepalive heartbeats.
  • Cross-Device Test Passed: Creating a booking on one client immediately reflects on the Admin live map and Driver
  available task list without page reload.
